# 内部步骤数据 v1

由看图的 Agent 生成，用户无需填写。输入 JSON UTF-8，图片仅允许位于 JSON 所在目录或其子目录（不允许绝对路径、越界或越界符号链接）。路径从 JSON 目录解析，与命令执行目录无关。可用带空格/中文文件名；不使用 shell 拼接用户文本。

```json
{
  "version": 1,
  "title": "关闭消息通知",
  "audience": "parents",
  "language": "zh-CN",
  "status": "draft",
  "notice": "待补全：尚未提供关闭后的截图。",
  "font_size": 44,
  "steps": [{
    "title": "打开设置",
    "action": "点击右上角齿轮旁的「设置」。",
    "image": "screens/01.png",
    "highlights": [[420, 120, 100, 60]],
    "arrows": [[400, 80, 430, 115]],
    "crop": [350, 70, 220, 180],
    "redactions": [[20, 30, 250, 40]],
    "check": "点击后检查是否出现「消息通知」。",
    "evidence": "本图仅展示设置入口。",
    "uncertainty": "关闭后的状态尚未提供。"
  }]
}
```

所有坐标都基于 **EXIF 方向校正后的全尺寸图片**，左上角为原点，x 向右、y 向下。矩形统一 `[x,y,width,height]`；箭头 `[起点x,起点y,终点x,终点y]`。边界为像素尺寸内；使用整数像素。先运行 inspect_images.py 查看方向校正图，尤其 EXIF 旋转 JPEG，不可使用未旋转存储尺寸。无须手动缩放或转换 crop 内坐标。脚本先在完整原图像素上脱敏、标注，再统一裁剪缩放，所以两种视图位置一致。

`highlights`/`redactions` 是矩形列表，缺省为空；`arrows` 缺省为空。`crop` 可选，用于全图之外的局部放大。`check` 是读者点击后的检查建议，`evidence` 只能写截图已证明的事实，`uncertainty` 明确未确定处。步骤必须有对应截图；不能用不存在的图片占位，缺图应询问或仅输出已知部分并标 draft。状态 complete 表示教学步骤齐备，不代表脚本确认实际业务操作成功。

字号 28..56 为 1000px 画布字号；默认父母 44、新手 40、客户/熟练者 36。最小字号不代表适合所有读者；根据目标手机实际阅读测试增大。页内文本过长会报错，不缩字号。每步不超过一张 A4；可拆分教学动作来保持图文同页。PNG 每段不超过 3000px，分段不拆步骤。

脚本不会识图、翻译、检测漏图、判断排序、判断模糊或识别个人信息。这些语义必须由宿主视觉检查。重复像素图仅提供警告；审核合理的重复动作可以保留。HTML 字符作为普通文本绘制，不生成或执行 HTML。不允许任意代码、模板表达式、外部 URL、命令或自定义输出文件名。输出固定为 guide.pdf、guide-01.png 等；输出目录必须为全新目录。

限制：最多40步、单文字字段4000字符、JSON 1MB、单图40MB/4000万像素、整份输入合计1亿像素，PNG/JPEG/WEBP。不同平台需提供覆盖简繁及英文的字体；`language` 只控制固定标签，不自动改写正文。
